# Security

If you find a security issue in rostr (the CLI, the API at api.getrostr.sh, the site, or the live counts Worker),
please email [hello@getrostr.sh](mailto:hello@getrostr.sh) instead of opening a public issue.

Say what you found, how to reproduce it, and what it lets someone do. We'll reply, work on a fix, and credit you when
it ships if you'd like.

Fixes go into the latest release, so check that you're on it (`rostr version`) before reporting.
